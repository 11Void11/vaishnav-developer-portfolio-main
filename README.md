# Vaishnav Developer Portfolio

Personal portfolio built with React, TypeScript, TanStack Start, Vite, and Tailwind CSS.

## Requirements

- Node.js 22 or a compatible current LTS release
- npm

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Preview the production build

```bash
npm run preview
```

## Deployment

The production build is configured for the Cloudflare Modules runtime through Nitro.
Review your deployment environment and required secrets before publishing.
